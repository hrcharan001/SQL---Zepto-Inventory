# SQL---Zepto-Inventory

This project focuses on inventory and pricing analysis using SQL on a Zepto-style retail dataset.It demonstrates the use of data exploration, cleaning, transformation, aggregations, grouping, conditional logic, and business analytics queries to extract meaningful insights from structured inventory data.

## Project Objectives

- Identify data inconsistencies and clean invalid records
- Transform pricing data (Paise → Rupees conversion)
- Analyze stock availability and product distribution
- Calculate estimated revenue by category
- Use aggregations, grouping, CASE statements, and filtering effectively.

## Learning Outcomes

- Improved ability to structure and analyze retail inventory datasets
- Hands-on practice with real-world pricing and discount analysis
- Enhanced data cleaning and transformation skills
- Strong understanding of revenue estimation logic
